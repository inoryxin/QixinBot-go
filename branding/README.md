# QixinBot 标识

角色形象：祈歆（白发猫耳 · 金瞳 · X 发夹），本仓库的标志即其头像版本。

| 文件 | 用途 |
|---|---|
| `logo-1024/512/256/128/64/48/32.png` | 圆角方形图标（仓库头像、应用图标、README） |
| `logo-round-512/128.png` | 圆形版本（会被裁圆的场合） |
| `logo-square-512.png` | 未做圆角的全幅方形 |
| `lockup-dark.png` / `lockup-light.png` | 横排字标（头像 + QixinBot + ONE BOT · MANY PLUGINS） |
| `favicon.ico` | 16/32/48/64 多尺寸 |
| `qixinbot-mark-vector.svg` | 矢量重绘版（可无限缩放，细节简化） |

最小可用尺寸 32px；48px 以下建议不要再用横排字标。
